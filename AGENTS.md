# Retired native RQT Telegram application

- This repository is retained for source provenance and wallet recovery. Do not deploy its app, restart its bot/export service, or clear encrypted wallet storage.
- Native RQT wallets use desktop, Android, web and the browser extension, with no active Mini App. The separate Telegram-only TON/jRQT product has no native RQT account, cross-chain bridge or conversion.
- Keep public documentation English and preserve upstream licenses, cryptographic compatibility and existing backup data. No secrets, recovery phrases or private backups belong in Git.
